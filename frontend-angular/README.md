# Frontend Angular 15

Interfaz Angular 15 + Angular Material + Tailwind CSS para el backend Node. No contiene fórmulas tributarias: solo carga archivos, envía contexto opcional y renderiza el JSON recibido.

```powershell
npm install
npm run build
npm start
```

Abre `http://localhost:4200`. En desarrollo consume `http://localhost:8001/api`.

Pantallas: Inicio, Cargar Excel, Resultado, Cómo se calcula, Detalle mensual, Diagnósticos, Historial, Configuración y Datos complementarios.
